# 🐣 Tamagotchi Vaiwu

**V.A.I.W.U. — Virtual AI Interactive Waifu Unit**

Тамагочи-вайфу на ESP32-S3: виртуальный питомец, мини-RPG и нейросетевой
помощник в одном карманном устройстве с 2.8" сенсорным экраном.

*A tamagotchi waifu for ESP32-S3: a virtual pet with RPG mechanics and an
AI companion in one pocket device with a 2.8" touch display.*

## Что умеет

- 7 персонажей со своими характерами, голосами и боевыми навыками
- Живые параметры: голод, счастье, энергия, дисциплина, вес; болезни и смерть
- Мини-RPG: пошаговые бои, 5 характеристик, уровни, экипировка, подземелья с боссами
- AI-помощник: чат через нейросеть, голосовой ввод, погода, таймеры,
  будильники, анекдоты — и всё это работает оффлайн по ключевым словам
- Она говорит: оффлайн-«лепет» на чиптюн-синтезе со своим тембром у каждого
  персонажа, либо настоящая речь через TTS
- Русский и английский интерфейс

## Части проекта

| Папка | Что внутри |
|---|---|
| [`firmware/`](firmware/) | Прошивка (ESP-IDF 5.5.x, C++20, LVGL 9.5) |
| [`server/`](server/) | Бесплатный self-hosted сервер распознавания речи (whisper.cpp + Caddy) |
| [`hardware/`](hardware/) | Плата, распиновка, корпус (STL для 3D-печати) |

## Быстрый старт

```bash
cd firmware
idf.py set-target esp32s3
idf.py menuconfig   # Wi-Fi и API-ключи (опционально — работает и оффлайн)
idf.py build flash monitor
```

Подробности — в [firmware/README.md](firmware/README.md).

## Статус

Прошивка собирается и работает на реальном устройстве
(Freenove ESP32-S3 2.8" Capacitive Touch Display). Последняя
проверенная на железе версия — **v4.9**.
