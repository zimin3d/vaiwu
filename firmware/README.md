# Tamagotchi Vaiwu

Виртуальный питомец-вайфу для **ESP32-S3** с цветным сенсорным экраном,
мини-игрой и нейросетевым общением (OpenRouter) с оффлайн-фолбэком.

Плата: **Freenove ESP32-S3 2.8" Capacitive Touch Display**
(freenove-esp32s3-display-2.8-lcd / fnk0104) — профиль железа подтверждён проектом
[xiaozhi-esp32](https://github.com/78/xiaozhi-esp32): ILI9341 (SPI, 20 МГц,
swap_xy+invert, BGR), ёмкостный тач FT6336 (I2C 16/15), кодек ES8311 (I2S) с
усилителем на GPIO1 (active-low), NVS для сохранений.

## Возможности

Интерфейс на русском и английском (переключение в настройках; кириллица -
собственные шрифты из DejaVu, `tools/gen_font.py`); часы (SNTP, Москва) в
статус-баре; меню настроек: язык, подключение к Wi-Fi прямо с экрана
(сканирование сетей + экранная клавиатура, креды сохраняются в NVS), сброс
игры, ползунки громкости и яркости экрана (значения сохраняются в NVS),
справка «О программе». Сцена-фон позади персонажа меняется по времени
суток (утро/день/вечер/ночь: солнце, облака, закат, луна со звёздами;
спрайты с прозрачным фоном). 7 персонажей (Aoi, Hina, Rin, Yuki, фурри-лисичка
Akane - кицунэ с ушками и хвостом, девочка-единорог Uni с рогом и пастельной
гривой и Колобок - круглый хлебный бок из сказки) с разными характерами
и модификаторами;
фигура меняется от веса (перекормишь - растолстеет, заиграешь - похудеет);
параметры голод/счастье/энергия/дисциплина/вес со скоростями из ТЗ (1%/2 мин,
1%/1.5 мин, 1%/1 мин; дисциплина 1%/10 мин — смягчено против ТЗ 1%/5 мин,
она восстанавливается во сне +1%/мин); состояния бодрствует/спит/грустит/болеет/умер;
5 действий (кормить, играть, умыть, туалет, поговорить); три мини-игры с меню выбора: «Угадай
эмоцию» (3 с на ответ), «Лови сердечки» (5 сердечек за 8 с), «Повтори
мелодию» (запомни 4 ноты); питомец озвучивает свои реплики: оффлайн-«лепет» (чиптюн-слоги из текста
фразы, свой тембр и темп у каждого персонажа) или настоящая речь через TTS,
если настроен сервер; режим переключается в настройках (выкл/лепет/речь);
у каждого персонажа свой боевой навык (лечение у Единорога, серия ударов
у Хины, точный удар у Рин, вытяжка у Юки, проказы с кражей золота у Акане,
защита у Колобка, вспышка у Аой); монстры иногда сами приходят к дому -
можно выйти в бой или остаться внутри; мини-РПГ «Поход»: за воротами ждёт слабый
монстр (слизень/нетопырь/гриб, с 3 уровня лиса-плутовка, с 5 - призрак,
с 7 - голем; у видов разные HP/атака/награда), пошаговый бой
(удар/навык/зелье/бегство),
HP и мана, опыт, уровни и раскачка пяти характеристик (сила, живучесть,
ловкость, магия, удача - у каждого персонажа свой стартовый набор,
он показан на экране выбора персонажа),
зелья покупаются в аптеке; экипировка: 8 предметов в трёх слотах
(оружие/броня/амулет) с бонусами к характеристикам, покупается в
магазине (страницы «Оружие», «Броня», «Амулеты»), меняется на экране «Вещи»
и продаётся там же за полцены долгим тапом; зелья здоровья и маны;
подземелье: 3-5 залов подряд с передышками, боссом и сундуком;
прокачка влияет на быт: очки сверх базы персонажа замедляют траты
(СИЛА - голод, ЖИВУЧЕСТЬ - энергия, МАГИЯ - настроение), ЛОВКОСТЬ
ускоряет сон, УДАЧА расширяет пороги здоровья;
тап по шкалам состояния открывает окно подробной статистики (проценты
шкал, вес/день/золото, HP/MP/XP, характеристики, надетые вещи) с выходом
в инвентарь; персонаж живёт в доме (камин, окно с небом по времени
суток), бой идёт снаружи на лугу; диалоговый экран с ответами Hug/Pat/Leave
(угощения живут в меню еды); магазин с пролистываемыми категориями
(еда / аптека / подарки);
экранная клавиатура для имени; 10 звуковых эффектов (чиптюн-синтез, без
файлов); автосохранение в NVS (после каждого действия + раз в 60 с);
онлайн-чат через OpenRouter (таймаут 3 с) и 150+ заготовленных фраз оффлайн.
Навыки помощника (RU/EN, распознаются локально или через ИИ): будильник и
напоминания, таймер и помодоро, анекдоты, текущее время, погода (Open-Meteo,
бесплатно, без ключа), офлайн-конвертер единиц (°C/°F, км/мили, кг/фунты),
свободные вопросы к нейросети. Ответы можно озвучивать голосом (TTS,
опционально - см. docs/VOICE.md).
Голосовой ввод (гибрид): на экране чата кнопка-микрофон «зажми и говори»
пишет с ES8311, отправляет WAV в облачный Whisper (OpenAI-совместимый STT),
распознанный текст идёт в тот же парсер команд и ИИ-чат; язык распознавания
следует языку интерфейса. Опционально - офлайн wake-word (ESP-SR), по флагу
Kconfig, см. docs/VOICE.md.
Экран ИИ-помощника (кнопка-клавиатура в статус-баре): свободные вопросы
уходят в нейросеть, а команды распознаются локально на RU/EN и работают
без сети - будильник на время ("поставь будильник на 7:30"), напоминание
через интервал ("напомни через 10 минут..."), анекдот, текущее время,
отмена будильников. Сработавший будильник показывает оверлей со звоном.

## Сборка (ESP-IDF v5.5.x)

```bat
%IDF_PATH%\export.bat
idf.py set-target esp32s3
idf.py menuconfig   :: Tamagotchi Vaiwu Configuration -> Wi-Fi и ключ OpenRouter
idf.py build
idf.py -p COMx flash monitor
```

Wi-Fi и API-ключ необязательны: без них игра полностью работает оффлайн.
Зависимости (lvgl 9.5, esp_lvgl_port 2.7, esp_lcd_ili9341 1.2, esp_codec_dev
1.5) подтянет component manager при первой сборке. После переименования
папок компонентов делайте `idf.py fullclean`.

## Структура

```
components/
  core/        интерфейсы (ILogger, ITouch, IStorage, INetwork, IAudio) + ConsoleLogger
  device_hal/  драйверы платы: SharedI2cBus, Ft6336Touch,
               Es8311Audio, NvsStorage, EspWifiNetwork (+ readLogical для LVGL)
  game/        чистая игровая логика (без ESP-IDF): VaiwuPet, персонажи,
               оффлайн-фразы, синтез звука - покрыта юнит-тестами
  chat/        NeuralChat: OpenRouter API + фолбэк, отдельная задача FreeRTOS
  ui/          DisplayDriver (ILI9341+LVGL) и VaiwuUi (все экраны), спрайты
main/          composition root + SoundService + Kconfig
assets/        PNG-превью спрайтов (заглушка, 7 эмоций)
tools/         gen_sprites.py (регенерация спрайтов), run_host_checks.py
tests/         юнит-тесты игрового ядра
```

## Проверка без железа

```sh
python3 tools/run_host_checks.py
```

Компилирует ядро игры (g++, -Werror), гоняет тесты, собирает host-ветки и
ESP-ветки нового кода против стабов IDF; при заданных `VAIWU_LVGL_DIR` /
`VAIWU_LVGL_PORT_DIR` дополнительно проверяет UI против настоящих заголовков
LVGL 9.5.

## Отличия от исходного ТЗ (осознанные)

- Пины дисплея/тача/звука взяты из подтверждённого профиля платы Freenove
  (xiaozhi-esp32), а не из таблицы ТЗ - таблица не соответствует этому железу.
- Экран в ландшафте 320x240 (так смонтирована панель на плате); компоновка
  экранов из ТЗ адаптирована.
- Сохранения в NVS вместо SD-карты (надёжнее, карта не нужна); спрайты
  зашиты во флеш (RGB565-массивы), а не читаются с SD.
- Имя питомца вводится латиницей (экранная клавиатура LVGL - QWERTY).
- Ночной сон «23:00-08:00» не реализован; принудительный сон по
  энергии < 15% работает. Часы (SNTP) показываются в статус-баре.
- XPT2046 (резистивный тач) не поддержан - на плате стоит ёмкостный FT6336.

## Прошивка заглушки

Спрайты-заглушки (4 персонажа x 7 эмоций = 28 шт) генерируются `tools/gen_sprites.py` (Pillow),
превью: `assets/sprites_preview.png` (4 персонажа x 7 эмоций). PNG - только превью,
в прошивку попадают C-массивы RGB565 из `sprites.c`. Замена на настоящие арты -
просто перегенерировать `sprites.c` из своих PNG 96x128.
